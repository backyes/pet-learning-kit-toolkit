# Exam alignment: turning prose into practice

Applies to KET (A2), PET (B1), FCE (B2), IELTS, and Chinese 高考/四六级 with the same skeleton; only the item types and the target level change.

## 1. Level tagging

Tag every vocabulary card. Learners need to know what to skip more than what to study.

| Tag | Meaning | Required mastery |
|---|---|---|
| `A2` | KET core | skip if the learner is above A2 |
| `B1` | **PET core** | recognise + spell + use in a sentence |
| `B2` | above the exam, frequent in authentic text | recognise + guess from context |
| `C1` | literary / low-frequency | recognise only |
| `熟词僻义` | familiar word, unfamiliar sense | **highest priority** — this is where marks are lost |

Rough counts from a 4,400-word literary chapter: A2 1, B1 68, B2 72, C1 90, 熟词僻义 6. If the distribution is skewed to one level, the tagging is lazy.

The 熟词僻义 set is worth building explicitly: `firm`(company), `nerve`(cheek), `common`(vulgar), `drive`(driveway), `bun`(hair bun), `stroke`(to stroke), `trick`(illusion), `last`(least likely).

## 2. The paraphrase table — highest-value artifact

Reading comprehension items paraphrase; they almost never reuse the source wording. Build a 40–50 row table:

| Source word | POS | Exam-side paraphrase | Note |
|---|---|---|---|
| mysterious | adj. | strange, unexplained | mystery + -ous |
| enraged | adj. | furious, very angry | en- + rage |
| downpour | n. | heavy rain | down + pour |
| come in handy | phr. | be useful | handy = 顺手 |

Two drills make it teachable:
1. cover the right column, recall the paraphrase;
2. cover the left column, recover the original — this is the Part 4 gap-fill skill in reverse.

## 3. Grammar mined from the text

Do not paste a grammar syllabus. Extract 10–12 structures that actually occur, with the real sentence:

| Structure | Sentence from the text | How the exam uses it |
|---|---|---|
| past perfect | they hadn't met for several years | tense chains in gap-fill |
| `as though` + subjunctive | as though it were waiting | grammar MCQ |
| `too … to` | too big to be allowed | paraphrase into `so … that … can't` |
| multiples | twice as tall as | listening numbers |
| participle clause | Wiping his streaming eyes, he … | writing upgrade |
| `must have been` | It must have been a trick of the light | deduction MCQ |
| negative inversion | neither as a cat nor as a woman had she fixed … | B2 reading |
| causative | made passersby stare / let himself into | `to`-insertion trap |

## 4. Writing frames

Collect 8 sentence patterns that the text demonstrates, then one model email (~100 words) and one model story/article (~110 words) written **using the kit's own vocabulary**.

Frame examples: `It must have been…`, `I couldn't help noticing that…`, `The first thing I saw was…`, `There was something strange about…`, `What surprised me most was…`, `I was so … that I …`, `As soon as …, I …`, `To my surprise, …`.

PET writing rubric reality: content completeness, organisation, accuracy, **range**. Two correctly used upgrade words beat ten misused ones — say so.

## 5. Listening tasks

Map the text to the exam's item types:

| Exam part | Task to build |
|---|---|
| PET Part 2 (multiple choice) | 2–3 T/F or 3-option items per section, on gist and detail |
| PET Part 3 (gap-fill, 1–2 words) | 4 gap-fills per section, drawn verbatim from the audio |
| PET Part 4 (T/F) | 2 statements per section, one true one false |
| dictation | 1 short sentence per section, with its own clip |

Rules that keep gap-fills fair: exactly one word per blank unless the exam allows two; the blank must be recoverable from the audio alone; do not blank articles or prepositions.

## 6. Spelling / dictation

See `practice.md` for the masking algorithm. Design notes:

- mask ~60% of letters, always keep the first and the last;
- show the Chinese gloss as the prompt — this tests spelling, not recall of the whole lexicon;
- accept case-insensitive input and normalise whitespace;
- error feedback must be positional: “第 4 个字母应为 `t`，你写的是 `d`”, plus a length hint when the lengths differ;
- “看答案” counts as a wrong answer (it goes to the wrong-answer book) — otherwise the book fills with words the learner never missed.

## 7. Reading plan

Close with a concrete schedule, e.g. 7 days for 13 units: read (no dictionary) → listen → annotate → drill → write → test → recall. State the completion bar explicitly: “5 条里过 3 条就进入下一章”, never “全部掌握再往下”.

## 8. Honesty about levels

CEFR labels are approximate. Say they are mapped from frequency/level heuristics, not from an official wordlist, and invite the user to correct specific tags.
